# Codex Swap Account v1.1.0

## What's new
- One-click Windows updates with verified downloads and a new per-user installer.
- Easier account login and reauthorization through the official browser flow.
- Improved compatibility with Codex Desktop process shutdown, relaunch and tray behavior.
- Detailed cached 5-hour and weekly limits when hovering over accounts.
- Clearer account status and optional tray limit indicators.
- Redesigned Support UI embedded in Settings.
- More compact Settings actions and improved overlay behavior.

## Fixes
- Fixed profile creation and auxiliary window behavior.
- Improved support amount inputs and Settings window lifecycle.

## Downloads
- `CodexSwapAccount-win-x64-setup.exe`: recommended per-user Windows x64 installer; no administrator privileges required.
- `CodexProfileOverlay-win-x64-portable.zip`: portable Windows x64 package.
- `SHA256SUMS.txt`: SHA-256 checksums for verifying downloads.

The installer preserves existing account profiles and settings. Close Codex Swap Account before a manual installation. Account switching continues to share Codex chats and sessions.
