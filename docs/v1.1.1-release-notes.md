# Codex Swap Account v1.1.1 Pre-release

## English

- Login and profile dialogs stay within a monitor's work area and reposition when the display layout or DPI changes. Browser sign-in is reachable from the taskbar. Login also handles missing CLI dependencies, cancellation, timeouts and lingering subprocess output more reliably.
- Profile removal now handles profiles and recovery storage on different drives, protects the active profile, and preserves recovery data if archiving or metadata updates fail.
- Simplified Chinese is available in the app and Windows installer. The app can select it automatically on Chinese Windows. Setup starts in English and offers Simplified Chinese in the language dialog. Thanks to **chyinan** for the translations and installer support. [PR #3](https://github.com/ZOONGG/codex-swap-account/pull/3)
- **Desktop Session Capture is experimental and opt-in.** To capture a signed-in session, choose **Add profile → Capture Desktop session** and confirm. Upgrading leaves existing auth-only profiles on their usual switch path. [Capture and recovery guide](DESKTOP-SESSION-RECOVERY.md)
- Interrupted auth-only switches are reconciled from a journal at startup or before the next switch. For a pending Desktop transaction, use **Open Codex** in the overlay tray and confirm recovery. Ambiguous recovery state is preserved for inspection.
- Background limit refresh, profile changes and backup cleanup coordinate access to profile files. Cleanup removes eligible retired Desktop data after a verified restart and a 24-hour grace period, while preserving pending transactions and skipping unsafe paths.

**Verification.** The local acceptance pass recorded 447/447 automated tests, WPF smoke checks in EN/RU/ZH, and Windows x64 package checksum verification. On GitHub-hosted Windows, the official v1.1.0 installer upgraded to the runner-built v1.1.1 and uninstalled successfully. Eight synthetic data files retained their hashes, and three WPF launches were confirmed by process and log checks. Both Windows workflows passed at `bbf39e447f4a118700cfdf8d50a19c57ff97adc8`. [Windows CI](https://github.com/ZOONGG/codex-swap-account/actions/runs/42510492627) · [Upgrade acceptance](https://github.com/ZOONGG/codex-swap-account/actions/runs/42510492683) · [Detailed report](v1.1.1-release-readiness.md)

**Known limits.** Real browser login, account switching, Desktop Capture and recovery against live Codex data remain unverified. Physical display disconnects, mixed-DPI transitions, interactive checks of the installed app and normal tray exit remain unverified. The original dual-monitor freeze in Issue #2 was not reproduced. The hosted upgrade used synthetic data and the runner-built installer. The exact local setup, the built-in update download path and migration of real v1.1.0 data remain unverified. The built-in updater offers stable releases only, so this Pre-release requires manual installation. [Issue #2](https://github.com/ZOONGG/codex-swap-account/issues/2)

## Русский

- Диалоги входа и добавления профиля остаются в рабочей области монитора и меняют положение при изменении конфигурации дисплеев или DPI. Окно входа через браузер доступно с панели задач. Улучшена обработка отсутствующего CLI, отмены, тайм-аутов и зависших потоков вывода дочерних процессов.
- Удаление профиля учитывает размещение профилей и хранилища восстановления на разных дисках, защищает активный профиль и сохраняет данные восстановления при ошибках архивации или обновления метаданных.
- Упрощённый китайский доступен в приложении и установщике Windows. Приложение может выбрать его автоматически в китайской Windows. Установщик стартует на английском и предлагает китайский в диалоге выбора языка. Спасибо **chyinan** за перевод и поддержку установщика. [PR #3](https://github.com/ZOONGG/codex-swap-account/pull/3)
- **Сохранение сессии Desktop — экспериментальная функция с явным согласием.** Для сохранения открытой сессии выберите **Добавить профиль → Сохранить сессию Desktop** и подтвердите операцию. После обновления существующие профили auth-only переключаются обычным способом. [Инструкция по сохранению и восстановлению](DESKTOP-SESSION-RECOVERY.md)
- Прерванное переключение auth-only восстанавливается по журналу при запуске или перед следующим переключением. При незавершённой Desktop-транзакции выберите **Открыть Codex** в трее оверлея и подтвердите восстановление. При неоднозначном состоянии данные сохраняются для диагностики.
- Фоновое обновление лимитов, операции с профилями и очистка резервных данных согласуют доступ к файлам. Очистка удаляет подходящие устаревшие данные Desktop после подтверждённого перезапуска и 24 часов ожидания, сохраняя незавершённые транзакции и пропуская небезопасные пути.

**Проверки.** Локальная приёмка зафиксировала 447 из 447 успешных автоматических тестов, WPF smoke на EN/RU/ZH и проверку контрольных сумм пакетов Windows x64. На Windows-раннере GitHub официальный v1.1.0 успешно обновился до собранного на раннере v1.1.1 и был удалён. Хеши восьми фиктивных файлов сохранились, три запуска WPF подтверждены по процессу и журналу. Оба Windows-прогона прошли на `bbf39e447f4a118700cfdf8d50a19c57ff97adc8`. [Windows CI](https://github.com/ZOONGG/codex-swap-account/actions/runs/42510492627) · [Приёмка обновления](https://github.com/ZOONGG/codex-swap-account/actions/runs/42510492683) · [Подробный отчёт](v1.1.1-release-readiness.md)

**Ограничения.** Вход через браузер, переключение реальных аккаунтов, сохранение и восстановление Desktop-сессий на реальных данных Codex пока не проверены. Также не проверены физическое отключение монитора, переход между мониторами с разным DPI, интерактивная работа установленного приложения и штатный выход из трея. Исходное зависание на двух мониторах из Issue #2 не воспроизведено. Приёмка обновления использовала фиктивные данные и установщик, собранный на раннере. Точный локальный установщик, загрузка через встроенное обновление и миграция реальных данных v1.1.0 остаются непроверенными. Встроенное обновление предлагает только стабильные выпуски, поэтому Pre-release устанавливается вручную. [Issue #2](https://github.com/ZOONGG/codex-swap-account/issues/2)
